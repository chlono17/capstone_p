# FEED 層

面向學校用戶（長庚大學）的社群介面，呈現 AI 處理後的知識輸出。

## 功能模組（待實作）

| 模組 | 說明 |
|------|------|
| `cards/` | 知識卡片：每筆知識帶標籤、摘要、延伸問題 |
| `podcast/` | Podcast 播放介面 |
| `interaction/` | 互動功能：對知識卡片提問、留言 |
| `editor/` | 發文介面：使用者寫作 + Agent 即時旁輔 |
| `profile/` | 個人動態：追蹤學習輸出狀況 |

## 注意事項

- 前端框架待定（React / Next.js 為主要候選）
