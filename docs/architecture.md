# 系統架構：Autonomous Knowledge Synthesizer

> 版本：Path A v0.1（待組員確認後可能調整）
> 最後更新：2026-05-10

---

## 概覽

**定位**：輸出驅動的學習社群平台，AI 降低輸出門檻，不替代輸出。
**技術核心**：本地 LLM（Ollama）+ RAG + Agent + MCP。

系統分為四層，資料從 INPUT 流入，經 AGENT 處理後存入 STORE，最終呈現於 FEED。

```
┌─────────────────────────── INPUT ───────────────────────────┐
│  手寫/相機(OCR)  │  語音(STT)  │  文字/Markdown  │  網頁/PDF  │
└──────────────────────────────┬──────────────────────────────┘
                               ↓
┌─────────────────── AGENT 處理核心（本地 LLM + MCP）──────────┐
│  知識萃取(Q&A對話)  │  格式化(手寫→MD)  │  輔助寫作(架構提示)  │
│  本地 LLM(Ollama)  │  RAG 檢索         │  Podcast 生成(TTS)  │
└──────────────┬──────────────────────────────────────────────┘
               ↓
┌──────────────────────────── STORE ──────────────────────────┐
│  Vector DB(ChromaDB/FAISS)  │  結構化DB(用戶/貼文/標籤)  │  媒體儲存  │
└──────────────┬──────────────────────────────────────────────┘
               ↓
┌──────────────────────── FEED（學校用戶）────────────────────┐
│  知識卡片(標籤/摘要/問題)  │  Podcast 播放  │  互動(問題/留言)  │
│  發文介面(使用者寫 + Agent 旁輔)  │  個人動態(學習狀況)         │
└─────────────────────────────────────────────────────────────┘
```

---

## 各層說明

### INPUT 層（`src/input/`）

使用者的知識輸入管道，支援多種格式：

| 輸入類型 | 技術 | 說明 |
|---------|------|------|
| 手寫 / 相機 | OCR（Tesseract / PaddleOCR） | 手寫筆記數位化 |
| 語音 | STT（Whisper） | 口述筆記轉文字 |
| 文字 / Markdown | 直接解析 | 最基本的輸入形式 |
| 網頁 / PDF | 爬蟲 / pdfplumber | 外部資料擷取 |

---

### AGENT 層（`src/agent/`）

系統的智慧核心，透過本地 LLM + MCP 完成知識處理：

| 功能 | 說明 |
|------|------|
| 知識萃取 | Q&A 對話形式，幫助使用者提煉重點 |
| 格式化 | 手寫 / 語音內容 → 結構化 Markdown |
| 輔助寫作 | 提供架構提示，協助使用者完成輸出 |
| RAG 檢索 | 從 Vector DB 找出相關知識片段 |
| Podcast 生成 | TTS 將知識卡片轉為可聆聽內容 |
| 本地 LLM | Ollama 作為推論後端 |

---

### STORE 層（`src/store/`）

三種儲存類型：

| 類型 | 技術選項 | 用途 |
|------|---------|------|
| Vector DB | ChromaDB / FAISS | 語意搜尋，RAG 的知識來源 |
| 結構化 DB | PostgreSQL / SQLite | 用戶資料、貼文、標籤 |
| 媒體儲存 | 本地檔案系統 / MinIO | Podcast 音訊、圖片 |

---

### FEED 層（`src/feed/`）

面向學校用戶的社群介面：

| 功能 | 說明 |
|------|------|
| 知識卡片 | 每筆知識帶標籤、摘要、延伸問題 |
| Podcast 播放 | 收聽 AI 生成的知識音訊 |
| 互動 | 對知識卡片提問、留言 |
| 發文介面 | 使用者寫作 + Agent 即時旁輔 |
| 個人動態 | 追蹤自己的學習輸出狀況 |

---

## 沙盒（sandbox/n8n-prototype）

`sandbox/n8n-prototype/` 是學習沙盒，讓團隊熟悉本地部署流程與 workflow 設計，
不是最終系統，但概念和 workflow 可以參考移植。

已完成：
- `docker-compose.yml`：n8n + LM Studio（port 5678 / 1234）
- workflow：`知識萃取對話系統`（knowledge-chat）、`notes-to-podcast`
- Obsidian vault：筆記管理，Git 自動同步

啟動方式：
```bash
cd sandbox/n8n-prototype
docker compose up -d
```
