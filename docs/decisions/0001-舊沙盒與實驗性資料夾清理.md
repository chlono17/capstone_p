# 0001：淘汰舊沙盒與實驗性資料夾

- **狀態**：已執行
- **日期**：2026-08-31

---

## 背景

專題題目已從「Autonomous Knowledge Synthesizer」轉向「IT 事件助理」（見 `CLAUDE.md`）。題目轉向後重新盤點 repo，發現有幾個資料夾已經沒有實際用途，但過去投入過不少心力，直接刪除會讓後來的人（或未來的自己）看不出「這件事其實做過、後來為什麼放棄」。這份文件記錄清理的決定與理由，讓歷史脈絡留在 repo 裡，而不是憑空消失。

清理範圍分兩批進行：

### 第一批（2026-08-30，隨題目轉向一併處理）

`sandbox/n8n-prototype/vault/` 及其 PARA 資料夾（`01_Projects`、`02_Areas`、`03_Resources`、`backlog`）——舊題目時期的 Obsidian 共筆 vault。因為團隊改用 Linear 做團隊協作（不再需要 Obsidian 個人知識庫工具），內容已搬遷為 Linear Document（team `capstone_p`）：

- 2026-04 / 2026-05 / 2026-06 學習筆記彙整
- 舊沙盒進度紀錄（歷史）
- Backlog / 待辦構想（歷史）
- Prompt 參考
- PARA 工作流反思（歷史決策記錄）

原始資料夾（含未進 git 的 `vault/raw/*.json`）備份於本機 `~/01_capstone/_archive_vault_2026-08/`，未上傳、未進 git 歷史。

### 第二批（2026-08-31）

**`sandbox/n8n-prototype/`（整個資料夾，docker-compose、n8n workflows、`.claude/commands`、`CLAUDE.md`、`SETUP.md`）**

淘汰原因：這個沙盒存在的唯一目的是「讓組員練習本地部署流程，並把知識萃取對話結果寫進 Obsidian vault」（見沙盒自己的 `CLAUDE.md`）。vault 已經在第一批清理中移除，這個沙盒的輸出端已經不存在，功能上等於失效。而且自 2026-05-10 之後，這個資料夾裡的實際檔案（docker-compose.yml、n8n workflow JSON）就沒有再被改動過，純粹是躺在 repo 裡的舊練習素材。

**`notes/Docker.md`**

淘汰原因：內容是「這個專題的日常指令速查」，直接寫死 `para_n8n` container 名稱與 n8n 相關操作，隨 `sandbox/n8n-prototype` 一起淘汰後這份筆記已經沒有對應的系統可操作。`notes/Git.md` 是通用 Git 教學，跟專題無關聯，予以保留。

**`sandbox/distributed-llm/`（Exo 分散式 LLM 推論實驗，M4 Mini + M1 Air）**

淘汰原因：這是舊題目時期評估「本地部署 + 推論優化」時做的實驗（比較 30B vs 9B 模型），最後一次有實質進度的 commit 是 2026-06-17，之後兩個多月沒有任何後續。目前判斷已經不會再繼續。

這個資料夾內含 `exo-src`，是指向 `exo-explore/exo`（上游開源專案）的 git submodule，但當初建立時漏了 `.gitmodules`，所以其實是一個斷掉的 submodule 參考——別人重新 clone 這個 repo 時，這個資料夾會是空的，一直以來只在原本設定過的本機上才看得到完整內容。清理前確認 `exo-src` 裡有兩個檔案（`placement_utils.py`、`system_info.py`）是還沒 commit 的本機修改，已先在該 submodule 自己的 git 歷史裡 commit 起來，確保修改不會遺失，才整個封存。

以上第二批資料夾備份於本機 `~/01_capstone/_archive_sandbox_2026-08/`（含 `distributed-llm/`、`n8n-prototype/` 兩個子資料夾，未進 git 歷史）。

---

## 決定

1. `sandbox/n8n-prototype/`、`sandbox/distributed-llm/` 兩個資料夾整個從 repo 移除（`sandbox/` 目錄本身也一併消失）。
2. `notes/Docker.md` 移除；`notes/Git.md` 保留。
3. 移除前一律先在本機備份一份完整內容，`exo-src` 這種有未存檔修改的先在自己的 git 歷史裡 commit 保存。
4. 這份決定記錄留在 `docs/decisions/`，作為之後有人問「n8n 沙盒/Exo 實驗跑去哪了」的第一個查詢點。

## 影響

- `CLAUDE.md`、`README.md`、`docs/architecture.md` 裡原本描述 `sandbox/n8n-prototype/` 的段落已同步更新為指向這份文件，不再保留過時的啟動指令。
- 之後如果又想重啟本地部署/分散式推論的實驗，可以直接從 `~/01_capstone/_archive_sandbox_2026-08/distributed-llm/` 取回，`exo-src` 的 git 歷史完整保留（包含封存前最後一次 commit）。
- `sandbox/` 目錄不存在了，若未來又有學習沙盒/實驗性質的東西，重新建立即可，不需要延續舊的資料夾結構。
