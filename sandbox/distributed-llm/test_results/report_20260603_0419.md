### ✅ Python 實作

```python
def binary_search(sorted_list, target):
    left = 0
    right = len(sorted_list) - 1

    while left <= right:
        mid = (left + right) // 2
        if sorted_list[mid] == target:
            return mid
        elif sorted_list[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

---

### 🔍 RAG 是什麼？

RAG 是一種結合「搜尋」和「生成」的技術。它讓人工智能在回答問題時，不僅依靠自己內建的知識（像是傳統的 LLM），還會去「找資料」，再根據找到的資料來生成回答。

---

### 🧠 RAG 的工作原理（簡單說明）：

1. **使用者提問**：比如問「2023 年什麼時候開放口罩購買？」
2. **RAG 先去「搜尋」**：它會去網路上或資料庫裡找最新資訊，比如最新的新聞或官方公告。
3. **再「生成回答」**：根據搜尋到的資料，生成一個準確、最新的回答。

---

### 🧩 RAG 如何解決 LLM 的「知識截止問題」？

很多 LLM（如傳統的 AI 模型）只學習到某個時間點的資料（例如 2023 年前的資料）。如果問題是「2024 年的總統選舉誰當選了？」，這些模型可能不知道，因為它的知識「截止」在 2023 年。

RAG 就是幫 LLM「補課」，讓它在回答時可以「查資料」，解決知識過時的問題。

---

**場景**：醫療問答系統

- **RAG 系統**：會先搜尋「最新糖尿病飲食指南」，再根據最新的醫學資料生成回答，比如說「現在建議糖尿病患者可以吃少量的蘋果、藍莓等低糖水果」。

有 `n` 個台階，每次可以爬 **1** 或 **2** 個台階。請問有多少種不同的爬法可以到達樓頂。

---

## 🧮 動態規劃思路

### 狀態定義：
設 `dp[i]` 表示到達第 `i` 個台階的爬法數。

### 狀態轉移方程：
因為每次可以爬 1 或 2 個台階，所以：
```
dp[i] = dp[i-1] + dp[i-2]
```
也就是說，到達第 i 個台階的方式數，是到達 i-1 個台階的方式數加上到達 i-2 個台階的方式數。

### 初始條件：
- `dp[0] = 1`：表示在地面上（0 個台階），只有一種方式（什麼都不做）。
- `dp[1] = 1`：表示只有一個台階，只能爬 1 步。

---

## ✅ Python 實作

```python
def climb_stairs(n):
    if n == 0:
        return 1
    if n == 1:
        return 1

    dp = [0] * (n + 1)
    dp[0] = 1
    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
```

---

## 📈 時間與空間複雜度分析

- **時間複雜度**：`O(n)`  
  我們只需要遍歷一次從 2 到 `n` 的每個數字。

- **空間複雜度**：`O(n)`  
  我們使用了一個長度為 `n+1` 的陣列 `dp`。
