## 摘要
1. 使用動態學習率（如 AdaGrad）解決 SGD 的步長挑戰。
2. 采用 Adam 優化器應用動量和動態學習率的概念。
3. 起用混合精度訓練（Mixed Precision Training）以節省資源並提高效能。

## 問答
**Q: 我想知道這在做訓練時，是因為gpu架構不同我訓練的程式需要特別調整讓他平行才會有效率，還是在那架構底下gpu自己就可以幫我們完成平行？**
[根據原文內容：
1. 當運算量與模型規模超出單一 GPU 的負荷時，需要採用平行訓練。
2. **資料平行（Data Parallelism）**：將訓練資料的批次（Batch）打散分配給不同的 GPU。每個 GPU 都擁有一份完整的模型與優化器副本，計算出局部的梯度後，再互相溝通（All Gather）整合成全局梯度。
3. **模型平行（Model Parallelism）**：分為兩種：**流水線平行（Pipeline Parallelism）** 和 **張量平行（Tensor Parallelism）**。]
在那架構底下 gpu 本身不會自動完成並行訓練，而是需要程式設計者根據模型特性和硬件架構來決定如何將模型分割和分配到不同的 GPU 上，然後編程協調不同 GPU 之間的通信和數據傳輸。

**Q: 我想知道如何使用資料平行（Data Parallelism）策略？**
[根據原文內容：
1. 將訓練資料的批次（Batch）打散分配給不同的 GPU。
2. 每個 GPU 都擁有一份完整的模型與優化器副本，計算出局部的梯度後，再互相溝通（All Gather）整合成全局梯度。]
使用資料平行策略時，首先需要將訓練資料的批次打散分配給不同的 GPU。每個 GPU 則運算其對應的部分，並計算局部梯度；然後通過全集操作（All Gather）將各個 GPU 的梯度整合成全局梯度，用於更新整個模型的參數。

**Q: 我想知道如何使用模型平行（Model Parallelism）策略？**
[根據原文內容：
1. 當單一 GPU 的記憶體裝不下整個模型時使用。
2. **流水線平行（Pipeline Parallelism）**：將網路按「層（Layers）」切割並分配到不同設備。
3. **張量平行（Tensor Parallelism）**：將目標層內的「參數張量」分割到不同設備上。]
使用模型平行策略時，當 GPU 記憶體無法容納整個模型時，可採用模型平行策略。其中包括將模型按層切割並分到不同設備上的流水線平行，以及將目標層內參數分割到不同設備上的張量平行。

**Q: 我想知道如何使用 ZeRO 優化器節省記憶體？**
[根據原文內容：
1. **ZeRO 的三個階段：** Stage 1（分割優化器狀態）與 Stage 2（分割梯度）能藉由資料平行的順風車達成通訊，並帶來極大的 GPU 記憶體節省。
2. Stage 3（分割參數）性質上類似於張量平行的變體，只在需要時傳遞參數。]
使用 ZeRO 優化器節省記憶體的方法包括採用 Stage 1 和 Stage 2 分割優化器狀態和梯度，以實現與數據平行的通訊並節省 GPU 記憶體；對於 Stage 3 分割參數，則只需在必要時發送參數。

**Q: 我想知道如何進行混合精度訓練？**
[根據原文內容：
1. 過去常用的妥協方法，將參數、激活值與梯度使用 FP16 格式。
2. 保留一份 FP32 的權重和優化器狀態副本作計算，動態縮放損失值以適應 FP16 的範圍。
3. 在較新的硬體（如 A100 與 H100）上，BF16 成為首選。因為它擁有和 FP32 相同的數值範圍。]
混合精度訓練首先將參數、激活值與梯度使用 FP16 格式，保留一份 FP32 的權重和優化器狀態副本作計算，動態縮放損失值以適應 FP16 的範圍。對於较新的硬件（如 A100 與 H100），BF16 成為首選，因為它擁有和 FP32 相同的數值範圍。
